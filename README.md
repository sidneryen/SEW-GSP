# SEW-GSP

Code and raw results for the paper

> Z. Ren, Y. Bao. *SEW-GSP: structure-aware evidence weighting and scalable geodesic neighborhoods for clustering-oriented dataset optimization.* Submitted to *Applied Intelligence*, 2026.

SEW-GSP is a preprocessing step for clustering. It moves boundary objects toward the cores of their clusters before any clustering algorithm (K-means, agglomerative clustering, DPC, ...) is run. It has three parts:

1. **CNLR feature weights**: cross-feature, permutation-calibrated Laplacian relevance with parameter-free, evidence-adaptive shrinkage.
2. **Exact geodesic K-NN**: computed by an early-terminated Dijkstra search, with O(NK) memory.
3. **Soft boundary-aware displacement**: boundary objects move in proportion to a soft membership score.

## Installation

```bash
pip install -r requirements.txt        # Python >= 3.9
```

## Quick start

```python
from sewsp.core import sewgsp
from sewsp.evalkit import load, cluster, scores

X, y = load('wine+N20')                 # Wine + 20 irrelevant features
Z = sewgsp(X, K=10, d=5)[-1]            # optimised data (in the learned metric space)
print(scores(y, cluster('KM', Z, k=3))) # ARI / NMI / ACC
```

## Data

| Group | Location | How to obtain |

| D1–D16 (SIPU, UCI, Iris, Digits, +N20 variants) | `data/*.gz`, scikit-learn | included |
| D17–D31 (scikit-feature high-dimensional sets) | `data/hd/*.mat` | `python fetch_data.py` |
| MNIST / Fashion-MNIST (70,000 x 784) | `data/large/` | downloaded automatically by `run_large.py` |

## Reproducing the paper

| Paper item | Command |
|---|---|
| Tables 3–6 (31 datasets, 8 optimizers, P1/P2 protocols, statistics) | `./run_pending.sh 2` then `python analyze2.py` |
| Table 7 (EWKM, sparse k-means, spectral clustering) | `python run_direct.py 2` |
| Table 2, last column (relevance profile) | `python relevance_profile.py` |
| Tables 8–10, Figs. 2–5 (noise, weight recovery, ablation, scalability) | `python run_extra.py all` |
| Table 11 (MNIST / Fashion-MNIST) | `python run_large.py --data mnist` and `python run_large.py --data fashion` |
| Figs. 2–6 | `python figures.py` |

All raw results used in the paper are already included in `results/`. For example, `results/main_all.csv` contains every (dataset, method, K, d, clusterer) run. Running `analyze2.py` and `figures.py` regenerates the tables and figures from these files without re-running any experiment.

**Note on Fig. 1.** The framework diagram (Fig. 1) was drawn by hand and is not generated by any script. Its editable source is `figs/fig1_framework.svg`, and the exported image is `figs/fig1_framework.png`. All other figures are produced by `figures.py`.

## Repository layout

```
sewsp/core.py      SEW-GSP, CNLR weights, truncated Dijkstra, HIBOG / HIAC' / HIACSP / HIACSP-WF, LS / MCFS baselines

run_*.py           experiment drivers         analyze*.py   statistics and tables
figures.py         figures                    results/      raw CSV results
```
